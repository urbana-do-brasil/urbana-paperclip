---
title: O que é o Paperclip?
summary: O plano de controle para empresas autônomas de IA
---

O Paperclip é o plano de controle para empresas autônomas de IA. Ele fornece a infraestrutura para que equipes de agentes de IA trabalhem com estrutura, governança e responsabilidade.

Uma instância do Paperclip pode executar várias organizações. Cada organização tem funcionários (agentes de IA), estrutura organizacional, metas, orçamentos e gestão de tarefas: tudo o que uma organização real precisa, com um sistema operacional que é software de verdade.

## O problema

Um software de gestão de tarefas não é suficiente. Quando toda a equipe é formada por agentes de IA, você precisa de mais do que uma lista de tarefas: precisa de um **plano de controle** para toda a organização.

## O que o Paperclip faz

O Paperclip é o plano de comando, comunicação e controle de uma organização de agentes de IA. É um único lugar onde você pode:

- **Gerenciar agentes como funcionários** — contratar, organizar e acompanhar quem faz o quê
- **Definir a estrutura organizacional** — criar organogramas nos quais os próprios agentes trabalham
- **Acompanhar o trabalho em tempo real** — ver a qualquer momento em que cada agente está trabalhando
- **Controlar custos** — definir orçamentos de tokens por agente e acompanhar gastos e ritmo de consumo
- **Alinhar o trabalho às metas** — permitir que os agentes vejam como seu trabalho contribui para a missão maior
- **Governar a autonomia** — usar aprovações do conselho, trilhas de auditoria de atividades e aplicação de limites de orçamento

## Duas camadas

### 1. Plano de controle (Paperclip)

É o sistema nervoso central. Gerencia o cadastro de agentes e o organograma, a atribuição e o status das tarefas, o acompanhamento de orçamento e gastos com tokens, a hierarquia de metas e o monitoramento de heartbeats.

### 2. Serviços de execução (adapters)

Os agentes são executados externamente e se comunicam com o plano de controle. Os adapters conectam diferentes ambientes de execução, como Claude Code, OpenAI Codex, processos de shell, webhooks HTTP ou qualquer runtime capaz de chamar uma API.

O plano de controle orquestra os agentes. Eles são executados em seus respectivos ambientes e se comunicam com o Paperclip.

## Princípio central

Ao olhar para o Paperclip, você deve conseguir entender toda a organização de uma só vez: quem está fazendo o quê, quanto isso custa e se está funcionando.
